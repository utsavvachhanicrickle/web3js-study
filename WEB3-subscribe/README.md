# 🚀 Real-Time Counter (Web3 + Events)

A simple Web3 project demonstrating:

* Smart contract development in Solidity
* Compilation using `solc`
* Deployment to a local blockchain (Hardhat)
* Interaction using Web3.js
* 🔥 Real-time updates using **events + subscriptions**

# 📁 Project Structure

```bash
realtime-counter/
│
├── contracts/
│   └── Counter.sol        # Smart contract
│
├── compile.js             # Compile contract
├── deploy.js              # Deploy contract
├── interact.js            # Interact (inc/dec/get)
├── subscribe.js           # Listen to events (real-time)
│
├── abi.json               # Generated ABI
├── bytecode.bin           # Generated bytecode
├── address.txt            # Contract address
│
├── package.json
```

# 🚀 Step-by-Step Execution

## 1️⃣ Start Local Blockchain

```bash
npx hardhat node
```

👉 Keep this running in a separate terminal

---

## 2️⃣ Compile Smart Contract

```bash
node compile.js
```

### Output:

* `abi.json`
* `bytecode.bin`

---

## 3️⃣ Deploy Contract

```bash
node deploy.js
```

### Output:

* Contract address printed
* `address.txt` created

---

## 4️⃣ Start Event Listener (🔥 Real-Time)

```bash
node subscribe.js
```

👉 This will listen for live contract events

---

## 5️⃣ Interact with Contract

Open a new terminal and run:

### ➕ Increment

```bash
node interact.js inc
```

### ➖ Decrement

```bash
node interact.js dec
```

### 📊 Get Current Count

```bash
node interact.js get
```

# 🧠 How It Works

## 🔹 Smart Contract

* Stores a counter (`count`)
* Emits event `CountUpdated` on every change

---

## 🔹 Events

```solidity
event CountUpdated(address user, uint256 newCount);
```

👉 Triggered using:

```solidity
emit CountUpdated(msg.sender, count);
```

---

## 🔹 Web3 Subscription

```js
contract.events.CountUpdated().on("data", callback);
```

👉 Listens to blockchain in real-time
