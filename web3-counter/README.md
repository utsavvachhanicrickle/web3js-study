# 🚀 Web3 Counter (Smart Contract + Web3.js + Hardhat)

This project is a simple end-to-end example of how to:

* Write a smart contract (Solidity)
* Compile it using `solc`
* Deploy it to a local blockchain (Hardhat)
* Interact with it using Web3.js

---

# 📌 Project Overview

We created a **Counter Contract** that:

* Stores a number (`myNumber`)
* Allows:

  * Reading the value
  * Setting a new value
  * Incrementing the value

---

# 🧱 Project Structure

```
web3-counter/
│
├── contracts/
│   └── MyContract.sol       # Smart contract
│
├── compile.js               # Compile Solidity → ABI + Bytecode
├── deploy.js                # Deploy contract
├── interact.js              # Interact with contract
│
├── abi.json                 # Generated ABI
├── bytecode.bin             # Generated bytecode
├── address.txt              # Deployed contract address
│
├── hardhat.config.js        # Hardhat config
└── package.json
```

---

# ⚙️ Setup Instructions

## 1. Install dependencies

```bash
npm install web3 hardhat solc
```

---

## 2. Enable ES Modules

In `package.json`:

```json
"type": "module"
```

---

## 3. Compile Contract

```bash
node compile.js
```

### Output:

* `abi.json`
* `bytecode.bin`

---

## 4. Start Local Blockchain

```bash
npx hardhat node
```

⚠️ Keep this running

---

## 5. Deploy Contract

```bash
node deploy.js
```

### Output:

* Contract address printed
* `address.txt` created

---

## 6. Interact with Contract

### Read value

```bash
node interact.js read
```

### Increment value

```bash
node interact.js inc
```

### Set new value

```bash
node interact.js set 20
```

---

# 🧠 How It Works (Simple Flow)

### 1. Solidity Contract

Defines logic:

* Store number
* Update number

---

### 2. Compilation (`compile.js`)

* Reads `.sol` file
* Uses `solc`
* Generates:

  * ABI → used to interact
  * Bytecode → used to deploy

---

### 3. Hardhat Node

* Local Ethereum blockchain
* Runs at:

```
http://127.0.0.1:8545
```

---

### 4. Deployment (`deploy.js`)

* Uses Web3.js
* Sends transaction
* Deploys contract
* Saves contract address

---

### 5. Interaction (`interact.js`)

* Uses ABI + address
* Calls contract functions:

  * `.call()` → read
  * `.send()` → write (transaction)

---

# 🔥 Key Concepts

| Concept  | Meaning                             |
| -------- | ----------------------------------- |
| ABI      | Interface to interact with contract |
| Bytecode | Compiled contract for blockchain    |
| Gas      | Fee for transactions                |
| call()   | Read data (free)                    |
| send()   | Write data (costs gas)              |

# ⚠️ Common Issues

### ❌ Hardhat node not running

→ Start:

```bash
npx hardhat node
```

---

### ❌ address.txt missing

→ Run:

```bash
node deploy.js
```

---

### ❌ require error

→ Use `import` (ES modules)

---

### ❌ Connection refused

→ Node not running on `8545`
