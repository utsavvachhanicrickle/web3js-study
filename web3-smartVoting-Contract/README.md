# 🚀 Web3 Smart Voting Contract

A simple Web3 project that demonstrates how to:

* Write a smart contract in Solidity
* Compile it using `solc`
* Deploy it to a local blockchain (Hardhat)
* Interact with it using Web3.js

---

# 📁 Project Structure

```bash
web3-smartVoting-Contract/
│
├── contracts/
│   └── Voting.sol          # Smart contract
│
├── compile.js              # Compile contract (ABI + Bytecode)
├── deploy.js               # Deploy contract to blockchain
├── interact.js             # Interact (vote, result)
│
├── abi.json                # Generated ABI
├── bytecode.bin            # Generated bytecode
├── address.txt             # Deployed contract address
│
├── package.json
└── node_modules/
```

---

# 🧱 Smart Contract Overview

The contract allows users to:

* ✅ Vote YES
* ❌ Vote NO
* 📊 View results
* 🚫 Prevent multiple voting (one vote per address)

# ⚙️ Prerequisites

Make sure you have:

# 📦 Installation

```bash
npm install
```

---

# ⚡ Step-by-Step Usage

## 1️⃣ Compile Smart Contract

```bash
node compile.js
```

### Output:

* `abi.json`
* `bytecode.bin`

---

## 2️⃣ Start Local Blockchain

```bash
npx hardhat node
```

⚠️ Keep this running in a separate terminal

---

## 3️⃣ Deploy Contract

```bash
node deploy.js
```

### Output:

* Contract address printed
* `address.txt` created

---

## 4️⃣ Interact with Contract

### Vote YES

```bash
node interact.js yes
```

### Vote NO

```bash
node interact.js no
```

### Check Results

```bash
node interact.js result
```

---

# 🧠 How It Works

## 🔹 Contract Logic

* Uses `mapping(address => bool)` to track voters
* Uses `require()` to block multiple votes
* Stores vote counts in blockchain

---

## 🔹 call() vs send()

| Method | Purpose    | Gas   | Example   |
| ------ | ---------- | ----- | --------- |
| call() | Read data  | ❌ No  | get votes |
| send() | Write data | ✅ Yes | vote      |

---

## 🔹 msg.sender

* Represents the user calling the contract
* Used to track who has voted

---

# ⚠️ Common Errors

### ❌ "Already voted"

* User already voted once
* Contract prevents duplicate voting

---

### ❌ address.txt missing

Run:

```bash
node deploy.js
```

---

### ❌ Connection refused

Make sure:

```bash
npx hardhat node
```

is running

---

# 💰 Gas Info

Each vote is a transaction and consumes gas because:

* It updates blockchain storage
* Writes to mapping and variables
